## 🎯 Aplikasi Tes Bakat Berbasis CliftonStrengths

website ini merupakan sistem asesmen yang digunakan untuk mengukur potensi bakat seseorang berdasarkan pendekatan CliftonStrengths.
Pengguna dapat mengerjakan serangkaian soal, kemudian sistem akan secara otomatis menghitung dan menampilkan hasil berupa bakat dominan.

## 🚀 Fitur Utama
✅ Registrasi & Login User
✅ Pembelian produk tes 
✅ Pengerjaan soal tes bakat
✅ Perhitungan otomatis hasil tes
✅ Menampilkan Top Bakat Terkuat
✅ Dashboard user sederhana
✅ Integrasi pembayaran


CliftonStrengths adalah metode pengukuran bakat yang dikembangkan oleh Gallup untuk mengidentifikasi kekuatan utama individu.
Pendekatan ini berfokus pada pengembangan potensi, bukan kelemahan.

## 🛠️ Teknologi yang Digunakan
Backend: Laravel
Frontend: Blade 
Database: MySQL
Styling: Tailwind CSS
API: Laravel REST API

## ⚙️ Cara Menjalankan Project
Clone repository
git clone https://github.com/rezariswandhaaaa/bakattes.git
Masuk ke folder project
cd bakattes
Install dependency
composer install
npm install
Copy file environment
cp .env.example .env
Generate key
php artisan key:generate
Setting database di .env
Migrasi database
php artisan migrate
Jalankan server
php artisan serve
npm run dev
📊 Alur Sistem
User login / register
Masuk ke halaman produk
Pilih dan mulai tes
Menjawab seluruh pertanyaan
Sistem menghitung nilai setiap bakat
Menampilkan hasil berupa Top 3 bakat dominan
